# CNC Embroidery Machine
Raspberry Pi Pico based project 

### Hardware Components
- Raspberry Pi Pico 
- SLO-SYN 230-T Motor Driver
- bipolar stepper motor
- Singer 27 Sewing Machine
- Open Builds XL Linear Actuator
